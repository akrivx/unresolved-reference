# unresolved-reference

Essays on C++ and systems programming: things pointed at, not yet fully resolved.

Written as questions worth pressing rather than conclusions worth defending. Most of these start from hands-on exploration: building something, hitting a seam, and writing up what the seam actually revealed.

## Essays

- [C with stdlib: A Two-Tier Model of C++](essays/c-with-stdlib.md): why C++ code that looks like C is correct application-layer style, not unfinished C++, argued through one small RAII example evolved twice. Ends with a question for engineers and a question for language designers.
